03 · How the two axes isolate the costs

The matrix supports two complementary slices. Neither slice alone is perfect; together with kernel-family timing they make the coefficient identifiable.

Hold N fixed; increase L

The number of active sequences stays constant while each sequence exposes more cached history. DSA indexer and MLA attention must inspect more KV; ordinary per-position MoE token count should remain approximately fixed.

8K each→ 32K each→ 80K each

Hold total KV fixed; increase N

Equal-total-KV pairs keep nominal scan volume constant while changing sequence count. The difference exposes per-sequence launch geometry, query-side work, scheduler state, and—unless removed—shared MoE work.

1 × 32K↔ 4 × 8K
Tstep = TDSA + TMLA + TMoE + Tother
Trank-sensitive = TDSA + TMLA the quantity most relevant when choosing among DPA ranks
Why total step time is not the desired coefficient:

MoE is synchronized across the TP/EP participants. Loading one DPA rank increases the shared MoE batch seen by every rank. If total step time is regressed directly against active requests, that shared work is incorrectly assigned to the loaded rank’s routing penalty.

05 · Exact execution sequence

The preserved runner makes every cell a cached-decode workload and prevents prefill latency from entering the measured region.

Create lanes

Generate 32 deterministic, distinct token-ID prompts, each 81,920 tokens long.

Warm the cache

Flush once, then submit every full-length lane before profiling begins.

Verify the hit

Require reported cached tokens to be within two tokens of the selected length.

Launch a cell

A thread barrier releases N requests together, all pinned to rank 0.

Trace and repeat

Capture GPU work, then visit all 24 cells in seeded randomized order.

06 · What the completed experiment should report

Each cell should produce per-step distributions, not merely one request-level duration. The same 24-cell panel should be reported for the three timing views below.

DSA + MLA

Rank-sensitive attention time. This is the primary surface for calibrating rank selection against active requests and resident KV.

router-relevant

MoE + collectives

Shared synchronized work. Report it explicitly so its request-count slope is not silently attributed to one candidate rank.

confound to subtract

Whole step

Observed critical-path time, including gaps. Useful as a reconciliation check: component timing must explain the end-to-end step.

reconciliation
Tattention ≈ β0 + βNN + βKKrank + βN²N2
residual check = Tstep − (Tattention + TMoE + Tcollective)

The fitted request coefficient is defensible only if it predicts held-out cells and the equal-total-KV pairs. A high whole-surface fit alone is insufficient if MoE remains inside the numerator.

07 · Guardrails before treating it as production truth

Status boundary:

The cluster attempt was cancelled during NCCL initialization, before model readiness. Therefore this page contains an experiment design and exact proposed inputs—no measured step times, fitted coefficients, or performance conclusions.

Three analysis checks required after a rerun
  • EAGLE work matching: group cycles by target verification width or accepted-token count. Different speculative outcomes can change per-cycle work even at the same N and L.
  • Steady-state selection: exclude graph capture, first-step setup, final partial batches, and cache-warm operations from the fitted window.
  • Production validation: replay natural mixed-rank traffic after the one-hot microbenchmark. The calibration is useful only if it improves prediction of the rank-sensitive critical path online.
