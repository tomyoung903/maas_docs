03 · Required configuration

The three changes

Two command-line arguments · one environment switch

Change 01

Two tokenizer workers

Before
1 worker
After
2 workers
--tokenizer-worker-num 2

Two HTTP/tokenizer processes parse and tokenize requests concurrently. Their prepared requests are merged into the same scheduler, preventing a fast PP8 pipeline from repeatedly exhausting its ready queue.

Change 02

Skip empty middle-chunk payloads

Before
ring circulation
After
payload omitted
SGLANG_PP_SKIP_PURE_CHUNKED_OUTPUT_COMM=1

A pure non-final chunk has no sampled token or logprob result to consume. The optimized path avoids serializing and circulating that empty output object while retaining the model-forward completion dependency.

Change 03

PP async depth two

Before
8 loop slots
After
10 loop slots
--pp-async-batch-depth 2

The scheduler can retire an older result while the current microbatch executes on the GPU. Depth two won over depths zero, one, and three by reducing exposed host and PP-boundary gaps.

Correctness prerequisite: do not enable the output-skip environment variable against the earlier experimental implementation that discarded the last-rank completion event. The accepted scheduler always waits for q_event before request or KV state can be recycled, and skips only the payload. Corrected scheduler_pp_mixin.py SHA-256: e706eb1c…31875.
