What PP8 Means on One Node

Each pipeline rank owns a consecutive model partition. A request advances through all eight stages before the sampled token returns to the API process. Pipeline microbatches may overlap, but every request still depends on all stages.

What is partitioned

Model layers and their parameters are split into eight pipeline stages. Stage-to-stage activations cross the node's local GPU fabric.

What is not partitioned

There is one data replica and tensor-parallel size one. This is not DP attention, and it does not divide one layer's indexer or attention operation across eight tensor ranks.

Exact Three-Hour Workload Semantics

“Do as many requests as possible” is implemented as a bounded backlog: source records remain in order, and every free client slot is refilled immediately. The replay does not preserve the source's original inter-arrival delays.

tend = t0 + D

t0 is the monotonic timestamp of the first formal admission. Model startup, smoke, and cache reset occur before it. At tend, no new request may be admitted; already-issued requests may drain for at most 3,600 seconds.

Internal TTFT: Scheduler Processing Entry to First Token

The primary number excludes the request's initial SGLang waiting queue, all client-side waiting, API dispatch before scheduler entry, and server-to-client delivery. It begins when the selected request enters its first model forward and ends when the sampled token IDs are CPU-visible.

Plainly: the primary internal TTFT starts after initial queueing, spans every prefill chunk plus any inter-chunk scheduling delay after first admission, crosses PP0 through PP7, and stops before optional log-probability materialization or response delivery. Execution Lifecycle

The flow is intentionally front-loaded with fail-closed gates. A GPU is claimed only after the source and node are both proven safe.

Confirm source at 19:00

Read the latest source location and revalidate identity before cluster mutation.

Find a strictly idle node

Check Kubernetes, GPU processes, utilization, memory residue, Docker commands, and checkpoint completeness.

Launch one temporary Pod

Pin one nonce-owned Pod to the qualified node and start the external collision guardian.

Prove one-token semantics

Run one isolated smoke request; require PP0–PP7 timing, one token, and zero decode.

Flush and mark boundary

Reset device and host cache state, then freeze the formal server-log start.

Issue for exactly three hours

Maintain the bounded backlog until the monotonic deadline, then stop new admissions.

Drain, join, and validate

Account for every request, build percentiles and token/cache totals, and checksum the result pack.

Release the node

UID-delete only the experiment Pod, stop its guardian, and prove all eight GPUs are released.

Safety, Collision, and Privacy Gates

Strict idle-node qualification

  • Node is Ready and schedulable.
  • Active Kubernetes GPU requests and limits are zero.
  • All eight GPU indices are present with no compute process.
  • Utilization is zero and memory residue is at most 10 MiB per GPU.
  • Running Docker containers and commands are inspected.
  • A remaining utility container requires two empty samples at least ten minutes apart.

Ownership and collision handling

  • A guardian outside the Pod checks GPU process cgroups throughout the run.
  • A foreign process invalidates the run; it is never signaled or restarted.
  • Cleanup uses the exact Pod UID and launch nonce.
  • A same-name foreign replacement is never deleted.
  • Only run-specific temporary resources and residue are removed.

Privacy-safe request evidence

  • Published rows retain deterministic IDs, numeric timing, tokens, cache counts, and sanitized completion type.
  • Prompts, messages, headers, generated text, token IDs, and arbitrary request extensions are excluded.
  • The request-logging patch is source-hash and anchor verified before SGLang import.

Failure posture

  • No idle node means continued read-only polling, not eviction.
  • Failed smoke or cache reset prevents the formal clock from starting.
  • Missing timing, rank, request, or privacy evidence prevents report certification.
  • Raw evidence is retained when safe cleanup is needed after failure.
