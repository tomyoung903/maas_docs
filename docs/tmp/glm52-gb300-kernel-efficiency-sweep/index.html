Definitions

Time, MFU, and MBU-min answer different questions

Primary time
union of correlated GPU kernel intervals inside one measured sample

Overlapping kernels count once. Kernel summed residency adds every interval and can be larger. The eager interval and its median time outside the union remain separate columns; that outside time is not automatically CPU overhead.

MFU
modeled FLOP ÷ primary elapsed seconds ÷ matching peak FLOP per second

The compute roof is selected per family. MFU is only as exact as the operation-count model.

MBU-min
modeled useful bytes ÷ primary elapsed seconds ÷ peak HBM bytes per second

“Min” matters: useful bytes omit cache-line amplification, retries, spills, and unrelated traffic. The denominator is Standalone peak HBM assumption at 8.00 TB/s.

Do not add MFU and MBU-min. They are separate normalizations of the same elapsed interval. A low value in both columns can indicate launch, synchronization, locality, instruction, or occupancy costs that neither useful-work floor captures.
MBU-min above 100% is not actual HBM utilization. DSA Index Candidate Scoring at B = 100 (103.40%) uses a modeled useful-byte floor divided by kernel-union time and peak HBM bandwidth. The fixed records are cache-hot; useful bytes are not measured DRAM bytes.

Limitations

What this page does not prove

  • Primary standalone timing is the per-sample union of correlated GPU kernel intervals. The dispatch-inclusive eager CUDA-event interval is retained separately; neither reproduces server scheduling, TP communication, neighboring model kernels, or CUDA Graph replay.
  • Selected-replay comparison is emitted only when the event-level mapping proves semantic ownership and the raw-symbol signature, common image/source provenance, launch configuration, and work-model join are exact. Nsight Systems did not export cubin hashes for this experiment. Missing or ineligible joins stay unavailable rather than being inferred from symbol order.
  • Selected-replay utilization reuses the standalone B=100 work model only after that strict join passes. Routed MoE MBU-min stays unavailable because production expert IDs were not captured, so its route-dependent unique-weight byte floor cannot be transferred.
  • MBU-min is a modeled useful-byte floor, not a hardware DRAM counter.
  • Excluded standalone family tp8_all_reduce: The source sweep did not produce six successful measured eager cases. Source status: not_standalone.
  • Excluded standalone family cuda_graph_host_launch: The source sweep did not produce six successful measured eager cases. Source status: not_standalone.
  • Independent node session epochs permit a diagnostic cross-node envelope, but its absolute value is sensitive to host clock skew.
  • Rank-local graph spans, kernel durations, and same-rank interval unions do not depend on cross-node clock alignment.
  • CUPTI start-to-end durations are residency intervals, not isolated arithmetic time or achieved occupancy.
  • The selected tree is one representative replay, not the entire matched request; a second complete replay is preserved with token role unassigned.
  • GB300-local semantic ownership is proven for 30 of 31 included standalone families; 30 pass the stricter exact standalone-to-replay join and the rest remain unavailable for comparison. No H200 symbol offsets or hardware assumptions are imported.
  • The matched request contains two complete implementation-equivalent CUDA Graph replays. This report uses the explicitly selected representative replay; response metadata cannot assign output-token roles to the two replays.
  • Eight standalone families use a deterministic correction overlay; two BMM families use a later superseding capture. The overlay manifest binds all input hashes and preserves unrelated primary rows in order.
