KV transfer speed: hardware floor vs deployment reality

The hierarchy restore path is modeled at 0.80 s; its optimistic hardware-reference floor is 0.15 s. The separate PP→DPA handoff has a 61 ms hardware floor but only a 1.99 s workload-throughput proxy. These values do not share the same measurement boundary.

What the observed column does—and does not—mean

Read before comparing
  • The 799 ms HiCache value is a serial estimate from two measured rates; layerwise GPU loads may overlap later compute. Its 150–152 ms reference floor is optimistic, not an end-to-end MNNVL guarantee.
  • The 1.99 s P→D value scales the formal run's aggregate throughput. It is not an isolated 1M-request latency measurement.
  • Do not use kv_transfer_speed_gb_s for this extrapolation: its Mooncake numerator covers all chunks, while its fallback timer begins after final-chunk submission.
