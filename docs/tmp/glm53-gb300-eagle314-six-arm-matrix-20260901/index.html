Experiment settings

RS means rejection sampling. We test the same three configurations under two target-sampling policies. The cohorts use different source requests, so compare configurations within the same cohort.

Two request cohorts

temperature 1.0 · top-p 0.95

Higher temperature and a wider top-p cutoff retain more of the target distribution.

temperature 0.7 · top-p 0.7

Bottom line

Rejection sampling is not a fixed acceptance multiplier. Its measured benefit depends strongly on the target sampling policy; draft top-p alignment is a smaller, policy-dependent correction. In the observed online request distribution, approximately 60% use temperature 1.0 / top-p 0.95 and approximately 40% use temperature 0.7 / top-p 0.7.
