Definitions and Governing Relationships

The table uses recomputed token ratios and the same trace-anchored, precision-normalized MFU convention for every experiment.

Pi=total prompt tokens in experiment i
Ci=server-reported cached prompt tokens in experiment i
Ni=Pi − Ci
hi=Ci / Pi
Ppeak=4 × 13,500 TFLOP/s = 54 PFLOP/s
MFUi=Fi,FP4-eq / (Δti × Ppeak)
Fi,FP4-eq is classified Tensor-Core model math allocated to the scheduler-selected stable interval. NVFP4 work is weighted ×1, FP8 ×3, and verified BF16 ×6 against dense B300 FP4 peak; unverified work is excluded rather than assigned an invented precision.

Plainly: cache hit is cached prompt tokens divided by all prompt tokens. Stable MFU is executed, precision-normalized model math divided by elapsed stable time and the four-GPU dense FP4 peak.
