Quality Gates and Limitations

  • target Neimeng node
  • isolated development namespace
  • production runtime image
  • whole-node GPU reservation
  • production node-local model root
  • host network
  • no restart
  • production NVFP4 checkpoint
  • tp/dp/pp 1/1/4
  • context 1048576
  • chunk and max prefill 32768
  • max running requests 80
  • FP8 KV page 64
  • prefill CUDA graphs disabled
  • cache reporting enabled
  • metadata request logging
  • radix-only controlled cache
  • CUDA profiler API range
  • no fixed profiler duration
  • force shutdown omitted

Limitations

  • Standalone prefill-shaped run, not a real disaggregated PD KV transfer.
  • Dynamo registration, Mooncake, and hierarchical cache are intentionally absent.
  • Server scheduler rows lack a joinable batch ID; exact per-request cache hits and completions come from the client JSONL.
  • MFU excludes cached-prefix work but includes new-suffix attention over the full 100K causal context.
  • Aggregate per-device kernel residency is not wall time, occupancy, or useful FLOPs.
  • NCCL SendRecv residency includes pipeline communication and synchronization waiting.
  • The runtime warned that the checkpoint scale format is not ue8m0 and that FP8-KV scaling factors default to 1.0; this profile is not an accuracy validation.
