Capacity divided by insertion rate

What the 12-minute number actually measures

It is the time needed for new uncached KV to equal the nominal pool capacity at steady full load. It describes pressure on the pool, not a timer attached to every request.

05

A cache hit is conditional

When does reusable KV still exist?

Recency is necessary only after the request is eligible to see the same cache. Four gates must all remain open.

1

Exact token prefix

Chat template, tools, model namespace, and token IDs must produce identical full pages from the root.

2

Reach its owner

The request must route to a worker or shard that owns the pages, unless KV is shared or transferred.

3

Already committed

The reusable boundary must have completed prefill and entered the page pool before this lookup occurs.

4

Survive pressure

Newer evictable KV inserted since the last touch must not exceed the effective available capacity.

Hits refresh recencyA popular shared header can remain resident through many nominal turnover cycles.
Bursts compress memory timeWall-clock retention shrinks when uncached insertion rises above its steady-load rate.
Effective capacity is localActive pinning, allocator pages, output KV, and routing determine which nominal pool a request can actually use.

Evidence contract

What was measured—and what remains an upper bound

This is an offline dataset analysis. No model forward pass and no GPU benchmark were used.

Exact accounting

  • Canonical dataset: 102,939 requests; 100,974 template-render successfully.
  • Exact GLM-5.2 runtime chat template and tokenizer; a preserved 4,810-request Europe total matched token-for-token.
  • Chained SHA-256 page identity over 64-token pages; final input token reserved at lookup.
  • Taiguo and Europe each start cold. No impossible cross-cluster reuse is counted.

Interpretation limits

  • Source-order commit before the next lookup is optimistic under concurrent execution.
  • Retention windows are strict last-touch counterfactuals, not a finite-capacity LRU replay.
  • Worker routing, active KV pinning, output-token KV, load imbalance, and allocator fragmentation are not modeled.
  • 1,965 malformed tool-argument requests are excluded from cache insertion.
