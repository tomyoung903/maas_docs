06 · Measurement semantics

What this TPOT does—and does not—measure

Client-visible SSE timing · fixed 128-token output

Single-delta caveat. 410 requests confirmed 128 completion tokens but exposed only one non-empty output delta. Their first and last output-delta timestamps are identical, so their client-observed TPOT is 0 ms. This does not mean the GPU generated 128 tokens instantaneously; it means the HTTP stream did not expose an inter-delta production interval. The CSV retains output_delta_events, and the report therefore presents both all-row and multi-delta distributions.
ClockClient monotonic clock captured on receipt of each non-empty SSE output delta.
DenominatorServer-reported completion_tokens − 1; exactly 127 intervals for every accepted row.
Included timeVisible span from first non-empty output delta to last non-empty output delta.
Excluded timeClient admission wait, request transport before first output, and prompt/prefill TTFT.
Speculative decodingCompletion usage counts accepted output tokens. EAGLE may expose more than one accepted token in an SSE delta; this client trace cannot recover hidden per-token GPU timestamps inside a delta.
InterpretationUse this as request-level client-observed inter-output timing for the exact P/D service. It is not a kernel-only decode latency and not a direct measure of one-token GPU step time.

3. Warm-up and formal cache boundary
  1. Run a shape-matched 80-request warm-up at 128 output tokens per request.
  2. Wait until frontend active, inflight, request-plane inflight, and router-pending gauges all equal zero.
  3. Invoke the discovered Dynamo prefill.clear_kv_blocks endpoint; require {"status":"success","message":"KV cache cleared"}.
  4. Invoke the discovered Dynamo backend.clear_kv_blocks endpoint; require the same success response. Each handler also clears its configured external HiCache backend.
  5. Start the formal replay only after both responses. No request was inserted between the clear boundary and formal request 1.

This preserves loaded weights, compiled kernels, communication setup, and process warm-up while removing local and external prefix-KV state. Cache hits during the formal run then emerge naturally from repeated prefixes in the ordered real trace.
