03 / Interpreting the result

Queue size reflects both entry and removal

What the measurements establish

PP0 has the highest mean on each of the eight pods, but another rank exceeds it in about one fifth of nonzero-inflight observations. Grafana's maximum-over-ranks is not interchangeable with PP0.

The same request may be represented in multiple rank-local queues. Adding all PP ranks would count those representations repeatedly.

What the code allows, not a measured cause

Intermediate-chunk KV sending does not enter this queue. Final-result processing does. Completion-confirmation propagation can also let PP0 remove requests before later ranks do.

Earlier computation does not imply a permanently larger queue. These gauge samples cannot identify which request, transfer, or scheduler delay caused any particular reversal.
