一段式端到端自动驾驶模型推理性能优化

文远知行 · 模型优化工程师 · AI 基础架构 · 2024.06 – 至今

  1. 面向 NVIDIA Orin-Y + QNX Safety + TensorRT 车端环境，负责端到端模型 Profiling 与性能优化；通过 INT8 量化、关键算子重写/融合及计算图优化，将推理延迟从约 210 ms 降至 130 ms（-38%）。
  2. 在图像编码模块中落地 QAT INT8 推理，采用权重 Per-Channel、激活 Per-Tensor 对称量化；对 LayerNorm 等精度敏感算子保留高精度，并优化 QDQ Placement 以保留 TensorRT Conv/Add Fusion，端到端延迟降低约 11 ms。
  3. 针对 Safety Runtime 下大矩阵拆分为多次 GEMM + Concat 的开销，基于 CUTLASS 实现 GEMM、GEMM+ReLU、GEMM+Add TensorRT Plugin，通过矩阵乘优化与 Epilogue Fusion 替换原执行链路，端到端延迟降低约 67 ms。
  4. 开发 RoPE TensorRT Plugin，并基于 Pattern Matching 实现 ONNX Graph Rewrite 规则，消除冗余 Cast、Reshape、Concat 等结构，减少 Kernel Launch 与数据转换开销。

CUDA GEMM Kernel 性能优化

个人项目

  1. 独立实现并优化 Jetson Orin（Ampere）FP32 GEMM 与 Jetson Thor（Blackwell）GEMM Kernel；在 4096×4096×4096 矩阵规模下，两平台均取得超过 CUTLASS 的性能。
  2. Ampere / FP32：构建全局内存、Shared Memory 与 Register 多级 Tiling，通过 cp.async、Shared Memory 多级流水线、Bank Conflict 消除、Register Ping-Pong 等优化，结合 Nsight Compute 分析访存、Warp Stall、指令吞吐及寄存器/Occupancy 权衡。
  3. Blackwell / INT8：围绕 TMA 搬运、Tensor Core MMA、Warp Specialization 设计多级异步计算流水线；分析 TMA 延迟与 Shared Memory 容量对在途数据量的约束，通过扩大 Tile、优化 L2 数据复用及 8×8 Grouped-Snake 遍历改善访存局部性并突破性能瓶颈。

家庭多渠道账单自动归集与入账 Agent

个人项目
