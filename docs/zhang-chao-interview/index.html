项目经历

腾讯项目

  1. 开展 Qwen3.5、GLM5.2、Kimi2.5、DeepSeekv4 等大模型的推理性能测试与优化。结合 NUMA 绑核、rocBLAS 算子寻优、零开销调度、并行策略调整及量化配置，在满足 SLA 延迟要求和服务稳定性的前提下，提升推理吞吐、资源利用率及高并发场景下的性能。
  2. 针对具身智能领域的 lingbot-va、fastwam、ACT 等模型，围绕 GEMM / Conv 的具体计算尺寸开展优化；通过调整卷积输入与权重的 channels-last 布局、使用 PyTorch / Apex 的 fused AdamW、启用 MIOpen TF32，以及对兼容的热点子图进行编译，改善计算与访存效率。在相关测试场景中，将性能由 A800 的约 60% 提升至 100% 以上。

个人总结

  1. 硬件与性能分析：熟悉 GPU 架构及 Kernel 执行模型，理解 SM、SIMD、Warp、Thread、VGPR、SGPR、LDS 等计算与存储资源，以及 Grid / Block 调度机制。能够结合硬件参数与 Profiler 分析，定位计算、访存及通信瓶颈，开展算子与部署方案优化，并完成性能验证。
  2. 大模型推理与部署：熟悉 PyTorch、TensorFlow 及 vLLM、SGLang 推理引擎，理解 Continuous Batching、Prefix Caching、Chunked Prefill、Radix Attention 等机制。熟悉 TP / PP / DP / EP / CP 并行策略，具备 IFB 与 PD 分离部署经验；掌握 W8A8、W4A8、W4A16 及 KV Cache 量化部署方法。
  3. 算子开发基础：了解 Triton 的使用方法，能够借助 Triton 实现和优化部分算子，并结合实际模型场景验证优化效果。
