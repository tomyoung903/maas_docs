项目一｜万亿参数 MoE 模型昇腾推理性能优化（vllm-ascend）

万亿参数混合专家模型（W4A8 量化、128K 上下文、MTP 投机解码）在 8 台 Atlas 800 A2（64 卡；TP8 / DP8 / EP64）上的 vLLM 推理服务优化，从"能跑"优化到"生产可用"。

  • 设计 prefill AllGather / decode MC2 分相混合通信，按 Cube / Vector / 通信引擎配对排班实现共享专家多流重叠；结合 MTP 投机解码 V2 调优，服务总吞吐 201.5 → 345.7 tok/s（+71.6%），平均 TPOT 156.3 → 91.0 ms（−42%），TTFT 中位数 20.8 → 7.4 s（−64%），GPQA 不降；
  • 独立定位并修复 4 个精度缺陷（归约顺序、torch.compile 分支固化、量化权重元数据缺失致投机接受率为 0 等），建立固定探针 + golden 逐层比对 + 单变量 A/B 流程；
  • 修复 MoE 激活量化 kernel 死行扫描（无效行扫描）：按有效行计算并放开 BF16 / group_index 限制，该 kernel 40× 加速，端到端 TTFT −44%，数值逐位不变；
  • 另完成零填充、KDA 层回写冗余、router GEMM 数据类型等优化项定位与验证。

项目二｜TurboQuant 4-bit KV Cache 压缩推理链（昇腾全栈）

2026.07 – 至今｜角色：团队构建 A2 端到端链；本人负责下一代昇腾 NPU 侧压缩 / 读取两算子（从零重写、性能标定、真卡验证），参与 A2 侧集成验证

  • 构建 4-bit KV Cache 端到端链：压缩写入 + 融合解压读取 + vllm-ascend 集成，面向 DeepSeek 系稀疏注意力 / GLM 系长上下文模型的 1M 长上下文推理；
