# 孙世牛面试准备页

只展示简历第一项核心项目「推理框架开发与模型部署」：保留项目日期、角色、背景、8 条一级 bullet 和 5 条嵌套 bullet。第二项 MaxKB / RAG 项目及个人联系方式、年龄、教育和工作履历未纳入。

从仓库根目录重建：

```bash
python3 tools/sun_shiniu_interview/build.py
```

源数据为 `content.json` 和 `questions.json`，输出仅写入 `docs/sun-shiniu-interview/`。页面沿用陈琦面试准备页的布局、添加/编辑问题和答案展开功能，初始问题列表为空。

每个一级或嵌套 bullet 都有独立稳定的 `id`；编辑器依原层级标为第 1、6.1、6.2 项等，引用时只取该 bullet 自身文字，避免重复包含子项。问题通过这些 ID 关联，浏览器存储键为 `sun-shiniu-interview:custom-questions:v1`，批注键为 `/sun-shiniu-interview/`，与其他候选人互不影响。

原文只去掉 PDF 水印和换行，未重新措辞或核实候选人的技术/性能主张。PDF 末项原有的 `23%–65%ß。` 按原文保留；`PP2/TP8` 经 PDF 页面目视核对，排除了布局提取中混入的水印数字。

共享批注脚本由 `docs/assets/maas-annotator.js` 提供。此目录不修改共享资源或首页。


## 选中文字添加问题

在同一条 bullet 的正文中选中任意连续片段，出现「为选中文字添加问题」按钮；可点击，也可按 `Alt+Q`。编辑器准确引用所选文字，保存后片段保留高亮，并在选区末尾附近显示编号。点击编号只引用并着重显示该片段；编辑、刷新和跨标签页同步保留原锚点。选择空白或跨 bullet 的范围不会创建入口，取消/Escape 会清理暂存选区。

原有顶部「添加问题」继续支持整段问题，已有 version 2 的浏览器数据无需迁移。存储对象可新增可选字段：

```json
{"textAnchor":{"start":10,"end":14,"quote":"所选文字"}}
```

`start`（包含）和 `end`（不包含）是 `.claim-text` 纯文本内的 UTF-16 字符偏移，与 JavaScript 字符串切片一致；`quote` 保存确切原文，包括空白。通过位置而非搜索文本区分重复短语。若正文变化导致偏移与原文不符，问题和原引用仍保留，编号回退至该段末尾并提示，不会把其他文字误标为引用。

高亮使用 CSS Highlights + DOM Range；不支持时以独立矩形覆盖层呈现。编号和覆盖层不写入 `.claim-text`，不改动原文或 `<strong>` 等格式，不与共享批注的 HTML 编辑记录竞争。共享批注处于编辑、删除或绘图模式时隐藏选中文字入口；其关闭或切回 pointer 后可继续使用。问题按钮及弹窗标为共享批注 UI，避免被其删除/编辑点击拦截；共享脚本本身未修改。


## 面试记录与汇总

每道题的弹窗新增三个初始为空的文本框：「候选人回答」「与预期的差距」「本题评价」。用户输入后 400ms 自动保存，也会在输入框失焦、切换题目、关闭弹窗、编辑题目、打开汇总和 `pagehide` 时同步保存。可见状态明确区分已保存与仅暂留页面的失败情况。

记录与题目分开保存，键为 `sun-shiniu-interview:evaluations:v1`，格式是 `{"version":1,"entries":{"<question-id>":{"answer":"...","gap":"...","evaluation":"...","questionText":"...","questionNumber":1}}}`。关联依据为稳定题目 ID，编辑题目或文本锚点不改变既有记录。保存时重新读取存储，只合并本标签页实际改动的字段；其他标签页的更新只刷新未编辑字段。写入失败时草稿仍保留在内存中供继续编辑和汇总复制；无法解析的存储不会被静默覆盖。

「汇总面试记录」只显示已有人工记录的题目与这三个字段，可逐题返回编辑。复制优先使用 Clipboard API；失败时显示并选中完整纯文本供手动复制。所有记录仅在当前浏览器及同源标签页间保存/同步，不生成参考答案、差距判断或总体评价，也不写入云端。
