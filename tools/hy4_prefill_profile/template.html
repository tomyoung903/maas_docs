Read the measurements correctly

GPU time

R = ∑ GPU activity durations (kernels, copies and memsets). U = duration of the interval union on one GPU. At the model root, U is the sum of four independent GPU unions, not a cross-device timeline. Neither is request latency.

Residency can include dependency waits. R − U describes overlap; it does not measure removable work.

MFU: matrix/dot model compute fraction

100 × ∑p(Fp / Pp) / T. Each precision class uses its matching nominal roof. The two tree values use T = U and T = R, respectively. This compares classified model matrix/dot work with nominal device capacity; it is not hardware occupancy or measured instruction utilization.

Whole-request target-model MFU uses the independent logical target-model numerator and T = four GPUs × completed client wall time. Auxiliary, draft and idle time remain in that denominator. The separate event-bound request value additionally requires complete trace/work joins. Scalar semantic counts are excluded; source arithmetic and padded issued instructions remain distinct.

Memory bandwidth

Useful-byte MBU estimate = 100 × useful interface bytes / (HBM roof × active-union time). This is not measured physical DRAM traffic. It can exceed 100% because interface accounting includes accesses that caches or on-chip reuse may serve without reaching HBM. Values are shown without clipping, and interface estimates are not summed through parents.

Counter MBU is separate and requires matching measured DRAM bytes. Missing roofs, counter evidence or a work-to-event join leave the value unavailable.
